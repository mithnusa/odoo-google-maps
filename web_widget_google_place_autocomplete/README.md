# Web Widget Google Place Autocomplete

## Overview

The `web_widget_google_place_autocomplete` module provides a new widget implementation using Google's NEW Places API. It offers enhanced autocomplete functionality with improved address mapping capabilities and configurable field mappings per country through a dedicated configuration interface.

## Installation & Configuration

1. Install the module (depends on `base_google_map`)
2. Configure your Google Maps API key with the NEW Places API enabled in `Settings > General Settings > Google Maps`
3. Configure country-specific address mappings in `Contacts > Configuration > Google Places Mapping`
4. Use the widget in your custom forms by specifying the appropriate widget in XML views
