# Base Google Maps

## Overview

The `base_google_map` module is the foundation for Google Maps integration in Odoo. It provides centralized Google Maps API configuration, API loading infrastructure, and base components used by all other Google Maps modules.

## Features
- Centralized Google Maps API key management in Odoo settings.
- Google Maps JavaScript API loader for consistent and efficient map rendering.
- Base components and utilities for building Google Maps views and features in Odoo.

## Installation & Configuration
1. Install the module.
2. Navigate to `Settings > General Settings > Google Maps` to enter and save your Google Maps API key.
3. Other Google Maps modules can now leverage this configuration for map-related features.
